# iVenture Studio Wiki Schema
Rules for maintaining the compounding knowledge base.

## Workflow
1. **Ingest**: Save source to `/llm-wiki/raw`.
2. **Synthesize**: Extract entities and concepts.
3. **Update**: Modify existing pages in `/llm-wiki/wiki`.
4. **Log**: Record action in `log.md`.
5. **Index**: Update `index.md`.

## Conventions
- Use Wikilinks: [[Page Name]]
- Include metadata in frontmatter.
- Maintain a clear hierarchy.
