# iVenture Studio — DEVELOPMENT BRAIN ARCHITECTURE
Version: 1.0 | Date: 2026-04-06 | Phase: 27.6

This document defines the cognitive relationship between the **VMOA Orchestrator (The Claw)** and the **Genspark AI Drive (The Library)**.

## 🧠 1. The Neural Flow
The "Brain" operates in a four-stage retrieval-synthesis loop:

1.  **Ingestion (Genspark Drive):** Raw unstructured data (PDFs, Docs, MD) is stored in the `/knowledge_base/` volume.
2.  **Indexing (Genspark Gateway):** The gateway automatically handles semantic indexing and vectorization.
3.  **Retrieval (Harness Connector):** VMOA Agents query the Drive via the `GensparkResourceConnector`.
4.  **Action (Harness RAAL):** The "Harness" validates the retrieved context and executes the final decision.

## 🏗️ 2. Structural Layers

### Layer A: The "Semantic Cortex" (Drive)
- **Path:** `/data/genspark2api/knowledge_base/`
- **Function:** Persistent, long-term memory of all iVenture decisions, research, and regulatory data.

### Layer B: The "Active Logic" (Harnesses)
- **Function:** Domain-specific build systems (`DeepResearch`, `Financial`, `Technical`) that enforce constraints and handle the loop-backs.

### Layer C: The "Inter-Harness Synapse"
- **Function:** How harnesses share data. 
- **Rule:** Harnesses never talk directly; they exchange "Artifacts" via the Genspark AI Drive. 
- *Example:* Financial Harness reads a "Market Cap Report" generated by the Deep Research Harness.

## 🛠️ 3. Development Protocol (The Brain's Growth)
- **Step 1:** Define the domain-specific logic in `specialized_harnesses.py`.
- **Step 2:** Add specific "Context Triggers" to the `ResourceConnector`.
- **Step 3:** Deploy documents to the AI Drive to "teach" the agent new skills.
